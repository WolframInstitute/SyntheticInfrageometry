## Usage

`FindInfraPerpendicular[graph, line, point]` returns InfraLine realisations through point perpendicular to line; n / UpTo[n] / All controls multiplicity.

## Details & Options

Options:

| Option | Values |
|---|---|
| `Method` | "Metric" (default; Euclid I.12 foot), "Projection", "Coordinate", "Arclength", "Alexandrov"; sub-options inside the spec forward to InfraPerpendicularQ |
| `"Radius"` | -- |
