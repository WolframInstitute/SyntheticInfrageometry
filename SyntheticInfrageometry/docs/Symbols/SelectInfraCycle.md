## Usage

`SelectInfraCycle[graph, cycles]` draws one cycle from the bundle in path-space (rotation-invariant metrics); n / UpTo[n] / All controls multiplicity.

## Details & Options

Operator form SelectInfraCycle[graph, n, opts][cycles].
