## Usage

`EnumerateGraphs[n, predQ]` returns all connected n-vertex graphs from GraphData satisfying predQ.

`EnumerateGraphs[n, predQ, k]` returns exactly k or $Failed; UpTo[k] returns up to k; All returns all.

## Details & Options

Option: "From" (override the default GraphData generator with a list).
