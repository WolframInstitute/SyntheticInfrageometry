## Usage

`PathSubgraph[graph, u, v]` returns the union of all shortest u-v paths.

`PathSubgraph[graph, u, v, k]` (or UpTo[k]) caps path length; PathSubgraph[graph, u, v, All] returns the full simple-path subgraph.

## Details & Options

Option: "Directed".
