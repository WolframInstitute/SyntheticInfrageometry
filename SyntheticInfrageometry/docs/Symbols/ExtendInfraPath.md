## Usage

`ExtendInfraPath[graph, path]` extends a walk per-step until inextensible and returns unary InfraPath[{walk}] wrappers; n / UpTo[n] / All controls multiplicity.

## Details & Options

Options Properties (as FindInfraPath), Method, "Length" (step budget), "Direction" ("BothSides" (default), "Forward", "Backward").
