## Usage

`FindInfraLine[graph, p1, p2]` returns one InfraLine wrapper of the maximal geodesic lines through p1 and p2; FindInfraLine[graph, segment] returns maximal lines containing segment; count n returns exactly n realisations or $Failed, UpTo[n] up to n, All (default) all.

## Details & Options

Options Properties ({}), Method ("Exhaustive" (default), "Greedy"), "Maximality" ("Extension" (default), "Diameter"), "Direction" ("BothSides" (default), "Forward", "Backward").
