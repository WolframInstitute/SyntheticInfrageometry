## Usage

$InfraPalette is a Dataset of the default object colors, one row per primitive with the color, the symbol naming it, and the wrapper heads drawn in it.

## Details & Options

It is the source the $Infra*Color symbols and InfraSceneHighlight's head-to-color dispatch both read from.
