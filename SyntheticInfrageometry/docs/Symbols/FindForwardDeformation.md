## Usage

`FindForwardDeformation[graph, walk, spec]` returns forward deformations of a walk A -> B (walks monotone in d(A, .)), grouped by the first-named axis of spec ("LengthDelta" / "DeformationSize"; each {x} exact, x upper bound, {lo, hi} range, bare name minimum); n / UpTo[n] / All sets the count per group.
