## Usage

`EmbeddingClosest[graph, bundle, ref]` keeps the bundle elements whose drawing under GraphEmbedding is Hausdorff-closest to the Euclidean reference: ref = {p1, p2} (segment), {center, radius} (circle), or a curve / point list.

## Details & Options

Wrappers are preserved; operator form EmbeddingClosest[graph, ref][bundle].
