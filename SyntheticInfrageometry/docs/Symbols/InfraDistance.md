## Usage

`InfraDistance[g, p, q]` is the graph distance between p and q, each a bare vertex or any Infra* wrapper, aggregated over the underlying vertex sets via the "Aggregation" option (Min default).

`InfraDistance[p, q]` is recognised inside InfraScene assertions.
