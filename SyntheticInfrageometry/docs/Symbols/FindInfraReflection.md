## Usage

`FindInfraReflection[graph, x, a]` returns a List of InfraPoint atoms, the reflections of x through a, where each x' satisfies B(x, a, x') and ax == ax'.

`FindInfraReflection[graph, x, a, n]` returns exactly n realisations or $Failed; UpTo[n] up to n; All (default) all.
